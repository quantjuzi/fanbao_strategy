# A 股短线因子研究说明

## 目标

把主观短线交易中常用的盘口、量价、情绪和题材信息，整理成可记录、可验证、可解释的因子框架。

当前阶段先解决三件事：

1. 明确每个因子怎么定义；
2. 明确数据来自哪里、属于什么时间点；
3. 用分组统计验证因子是否真的影响后续收益。

本文档不展示具体策略阈值，不把少量样本当成稳定结论。

## 因子分类

### 1. 量价因子

| 因子 | 定义 | 数据层级 | 观察用途 |
|---|---|---|---|
| 成交额 | 当日成交金额 | 日线 | 流动性和资金关注度 |
| 竞价涨幅 | 开盘价 / 前收盘价 - 1 | 竞价 | 开盘强弱 |
| 实体涨幅 | 收盘价 / 开盘价 - 1 | 日线 | 日内真实强度 |
| 实际换手率 | 成交量 / 自由流通股本 | 日线 | 交易活跃度 |
| 自由流通成交额比 | 成交额 / 自由流通市值 | 日线 | 相对于可交易盘的成交活跃度 |
| M7/M20 | 7 日均线 / 20 日均线 | 日线 | 短期趋势位置 |

### 2. 连板与涨停结构

| 因子 | 定义 | 数据层级 | 观察用途 |
|---|---|---|---|
| 连板数 | 连续收盘涨停的天数 | 日线 | 辨识度和情绪层级 |
| 昨日是否涨停 | 上一交易日是否封板 | 日线 | 情绪延续或断板反包 |
| 首封时间 | 当日第一次封板时间 | 分钟线 | 封板主动性 |
| 开板次数 | 当日涨停打开的次数 | 分钟线 | 封板稳定性 |
| 封单金额 | 涨停时买一封单金额 | L1/L2 | 封板强度 |
| 封成比 | 封单金额 / 当日成交额 | L1/L2 | 封单相对成交的强度 |

### 3. 竞价与盘口因子

| 因子 | 定义 | 数据层级 | 观察用途 |
|---|---|---|---|
| 竞价换手率 | 竞价成交量 / 自由流通股本 | 竞价 | 开盘参与度 |
| 竞价走势 | 9:15-9:25 价格变化路径 | 竞价明细 | 抢筹或出货倾向 |
| 委买委卖比 | 委买量 / 委卖量 | L1/L2 | 买卖盘瞬时强弱 |
| 内外盘比 | 主动买入量 / 主动卖出量 | Tick/L2 | 主动成交方向 |
| 盘口撤单率 | 撤单量 / 挂单量 | L2 | 虚假挂单风险 |

### 4. 题材与情绪因子

| 因子 | 定义 | 数据层级 | 观察用途 |
|---|---|---|---|
| 题材标签 | 个股所属主要炒作题材 | 人工/数据 | 资金选择方向 |
| 同题材涨停数 | 当日题材内涨停家数 | 日线 | 板块共振强度 |
| 题材排名 | 题材当日涨幅或资金热度排名 | 日线/分钟 | 主线识别 |
| 龙头状态 | 题材龙头是否涨停或走强 | 日线/分钟 | 板块持续性 |
| 涨停家数 | 全市场涨停家数 | 日线 | 市场情绪温度 |
| 炸板率 | 炸板数 / 涨停触及数 | 日线 | 情绪退潮风险 |

## 数据层级

| 层级 | 能解决的问题 | 不能解决的问题 |
|---|---|---|
| 日线 | 涨跌、成交额、连板、均价 | 首封时间、开板次数、盘口变化 |
| 分钟线 | 日内节奏、封板时间、分时强弱 | 逐笔主动买卖和撤单 |
| L1 | 五档盘口、封单金额 | 订单流完整还原 |
| L2/Tick | 逐笔成交、主动买卖、撤单 | 仍需处理隐藏单和拆单 |

因此不能把日线无法观察的盘口信息伪造成因子。数据没有到 L2 级别时，应明确写“暂不可计算”。

## 验证方法

每个因子只做三件事：

1. 在信号时点取值，禁止使用未来数据；
2. 按分组或分位数统计后续收益；
3. 同时比较样本数、胜率、平均收益、盈亏比和最大回撤。

不能只看“某因子高的股票涨得多”，还要检查：

- 样本是否足够；
- 是否受少数极端样本影响；
- 是否和市场整体环境混淆；
- 是否在涨停无法成交时产生虚假收益。

## 当前实现顺序

1. 日线量价和连板结构；
2. 竞价涨幅和竞价换手率；
3. 题材共振和板块强度；
4. 分钟线首封时间、开板次数；
5. L1/L2 委买委卖比、内外盘、封成比和撤单率。

具体阈值和策略参数保留在本地私有目录，不公开到仓库。
