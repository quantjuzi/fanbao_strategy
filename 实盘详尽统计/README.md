# 实盘详尽统计

过去一年大致按照反包、趋势高开和连板接力三种策略买股，
其中主要是反包。新股和其他交易单独统计。
每个分类的全部交易放在一张表里，日期只保留到日。

- 成交记录：1,365 条
- 买入成交：716 条
- 卖出成交：649 条
- 已清仓交易回合：440 个
- 东方财富账户最终净盈利：66,886.58 元
- 已清仓交易净盈亏：68,901.09 元

多笔买入和多笔卖出合并成一个交易回合。
