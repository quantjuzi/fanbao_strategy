# 实盘详尽统计

这里集中放实盘交易分类后的统计和股票明细。
每个分类都按买入日期分批列出全部交易，日期只保留到日。

## 数据口径

- 成交记录：1,365 条
- 买入成交：716 条
- 卖出成交：649 条
- 交易回合：441 个
- 已清仓交易回合：440 个
- 未清仓：N力勤 500 股
- 东方财富账户最终净盈利：66,886.58 元
- 已清仓交易净盈亏：68,901.09 元

成交记录和交易回合不是同一种口径。同一只股票连续持仓期间，
多笔买入和多笔卖出合并成一个交易回合，卖到 0 后才算清仓。
