# 反包策略时间口径（T = 买入日）

> 与 README 保持一致：**T 是买入日**，代码和文档都用同一套叫法。

## 时间轴

| 名称 | 相对买入日 | 发生什么 |
|---|---|---|
| 涨停日 | T-2 | 股票涨停过 |
| 断板日 | T-1 | 出信号：未涨停、成交额大于 15 亿、M7/M14 > 1、实体跌幅大于 -3% |
| 买入日 | T | 开盘价买入 |
| 卖出日 | T+1 | 收盘价卖出 |

## 代码对应关系

| 代码 | 对应的时间 | 含义 |
|---|---|---|
| `zt_Tm2` | T-2 涨停状态 | `shift(1)` 把涨停列往下挪一行，当前行是断板日 T-1，往上就是 T-2 |
| `df["信号"] == 1` 的行 | T-1 断板日 | 五个条件同时成立，出信号 |
| `buy_days.iloc[0]["open"]` | T 日开盘价 | 断板日次日开盘买入 |
| `sell_days.iloc[0]["close"]` | T+1 日收盘价 | 买入日次日收盘卖出 |

## 为什么不能断板日当天买

断板日（T-1）的成交额、是否涨停、均线都是收盘后才知道的，盘中看到的价格不完整。所以信号只能等收盘后确认，实际操作最早是次日（T）开盘买，否则就是用了未来数据。

## 一句话讲给面试官

策略在断板日（T-1）收盘后确认信号，T 日开盘买入，T+1 日收盘卖出，整个流程符合 A 股 T+1 规则，也不存在未来函数。

## 常见坑

- 不要把出信号的日子叫 T，那是断板日 T-1。
- `shift(1)` 拿的是 T-2 的涨停状态，不是 T-1。
- 买入用的是开盘价，卖出用的是收盘价，改的时候别把价格用错。
