# Python 开窍卡片（手机速读版）

> 用法：每天花 5 分钟，一段一个场景。看完代码只问自己一句：  
> “这行在做什么交易操作？” 而不是“这个语法叫什么？”

## 心法（先记这一句）

- 你每天做的事决定代码结构，不是反过来。
- 代码 = 把你每天的交易动作，翻译成机器能懂的语言。
- 看代码时，先想“这行在干嘛”，答得出来就是懂了。

## 6 个场景速记

1. **列表** = 一串东西，就是你的选股清单  
   `today_stocks = ["000001", "000002"]`

2. **字典** = 带标签的盒子，想取价格就喊一声  
   `stock["price"]`

3. **for** = 对每一个，做以下操作  
   `for code in today_stocks:` → 逐个取出，每个都执行一次下面的事

4. **if** = 如果……就……  
   `if amount > 1500000000:` → 满足条件才执行下面

5. **函数** = 把固定流程打包、起个名字，以后每天调用一次  
   `def daily_select():`

6. **print** = 打印到屏幕让你看见，不做其他任何事

## 最容易卡的点：print ≠ 放进去

| 你想做的 | 对应代码 |
| --- | --- |
| 放进去（存起来） | `selected.append("000001")` |
| 显示出来（看一眼） | `print(selected)` |

`print` 只负责让你看见。要存东西，必须用 `.append()` 之类真正存数据的操作。

## 每日选股流程（参考骨架，不是固定模板）

| 你每天做的事 | 对应代码 |
| --- | --- |
| 1. 读数据 | `df = pd.read_csv("daily.csv")` |
| 2. 看前几行确认 | `print(df.head())` |
| 3. 筛换手率 > 20% | `df = df[df["turnover"] > 20]` |
| 4. 筛成交额 > 15 亿 | `df = df[df["amount"] > 1500000000]` |
| 5. 按评分排序 | `df = df.sort_values("score", ascending=False)` |
| 6. 取前 5 只 | `result = df.head(5)` |
| 7. 打印看看 | `print(result)` |

注意：这只是参考骨架。你可以先筛成交额再筛换手率、可以只筛不排序、可以先剔除 ST 停牌。流程完全由你的策略决定。

## 量化项目总流程（宏观骨架）

```
数据获取 → 数据清洗 → 策略逻辑 → 回测 → 结果输出
```

| 环节 | 你做的事 | 对应代码 |
| --- | --- | --- |
| 数据获取 | 拿数据 | `pd.read_csv()` |
| 数据清洗 | 去掉 ST、停牌、空值 | `df = df[df["turnover"] > 20]` |
| 策略逻辑 | 按规则筛选 | `df = df[df["amount"] > 1500000000]` |
| 回测 | 看历史表现 | `for` 循环模拟每天交易 |
| 结果输出 | 看成绩单 | `print` 或 `to_csv()` |

记住顺序：拿数据 → 洗干净 → 算信号 → 跑回测 → 看结果。这是以后做任何量化策略的骨架。

## 回测不是单独的一步：一个完整例子

目标：验证“换手率大于 20% 的票，第二天表现更好”。

```python
import pandas as pd

# 1. 数据获取：读入全年数据
df = pd.read_csv("daily_data.csv")

# 2. 数据清洗：去掉 ST、停牌
df = df[~df["name"].str.contains("ST")]
df = df[df["amount"] > 0]

# 3. 策略逻辑：标记换手率大于 20% 的信号日
df["signal"] = df["turnover"] > 20

# 4. 回测：取信号日的第二天涨跌幅，算平均
df_signal = df[df["signal"] == True]
avg_return = df_signal["next_pct"].mean()

# 5. 结果输出：看信号次数和平均收益
print(f"信号次数：{len(df_signal)}")
print(f"平均收益：{avg_return:.2%}")
```

回测不是单独的东西，它就是“看历史结果”这一步。前面三步都是为了这一步服务：数据是素材，信号是规则，输出是结论。
