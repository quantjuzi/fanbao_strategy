# 单语法速查表（小白版）

用法：在代码里看到一个语法，就来这里查。查完回到代码里读一遍。

复合语法不用怕，它只是多个单语法拼起来的。先学会下面的每一步，长代码就能拆开看。

## 一、基础语法

| 语法 | 例子 | 意思 | 什么时候用 | 常见坑 |
|---|---|---|---|---|
| `import` | `import pandas as pd` | 导入工具包 | 用别人写好的功能 | 后面用 pd 代替 pandas |
| `print` | `print(x)` | 打印结果 | 看代码输出 | 括号别漏 |
| `type` | `type(x)` | 查数据类型 | 不知道是什么类型 | 结果看 `<class ...>` |
| `len` | `len(trades)` | 数数量 | 统计笔数 | 列表、字符串都能用 |

## 二、判断和循环

| 语法 | 例子 | 意思 | 什么时候用 | 常见坑 |
|---|---|---|---|---|
| `if` | `if close > open:` | 如果满足条件 | 条件成立才执行 | 后面要冒号和缩进 |
| `elif` | `elif close == open:` | 再判断一次 | 多个分支 | 不是 else if |
| `else` | `else:` | 否则 | 前面都不成立时 | 不能单独使用 |
| `for` | `for i in range(3):` | 循环 | 重复处理 | 循环体要缩进 |
| `continue` | `continue` | 跳过这一次 | 遇到没数据就跳过 | 后面的代码不执行 |
| `while` | `while count < 3:` | 满足条件就一直做 | 不确定循环次数 | 条件永远成立会卡死 |
| `range` | `range(3)` | 生成 0、1、2 | 控制循环次数 | 不含最后一个数 |

## 三、函数和字符串

| 语法 | 例子 | 意思 | 什么时候用 | 常见坑 |
|---|---|---|---|---|
| `def` | `def run(df):` | 定义函数 | 打包一段逻辑 | 后面要冒号 |
| `return` | `return x` | 把结果交出去 | 函数末尾 | return 后面不执行 |
| `lambda` | `lambda x: x + 1` | 一行小函数 | rolling / apply 里传逻辑 | 复杂逻辑不要用 |
| `f"..."` | `f"胜率 {p:.1%}"` | 把变量塞进字符串 | 打印报告 | 变量要放在 `{}` 里 |

## 四、数据结构

| 语法 | 例子 | 意思 | 什么时候用 | 常见坑 |
|---|---|---|---|---|
| 列表 | `[1, 2, 3]` | 一串值 | 存多笔交易 | 索引从 0 开始 |
| 字典 | `{"a": 1}` | 键值对 | 存配置 | 键在左边，值在右边 |
| `append` | `trades.append(x)` | 末尾加一个值 | 收集结果 | 不是赋值 |
| `int / float / str / bool` | `int("10")` | 类型转换 | 数据格式不对时 | 转不了会报错 |

## 五、pandas 单语法

| 语法 | 例子 | 意思 | 什么时候用 | 常见坑 |
|---|---|---|---|---|
| `pd.read_csv` | `df = pd.read_csv(path)` | 读 CSV 文件 | 开始处理数据 | 路径别写错 |
| `pd.to_datetime` | `df["日期"] = pd.to_datetime(df["日期"])` | 字符串转日期 | 日期排序、比较 | 不转会排错 |
| `df["列"]` | `df["close"]` | 取一列 | 算指标 | 列名要用字符串 |
| `df["新列"] = ...` | `df["M7"] = ...` | 加一列 | 算均线、信号 | 会直接改这张表 |
| 行筛选 | `df[df["信号"] == 1]` | 只留条件成立的行 | 选出信号股 | 条件要返回 True / False |
| `.copy()` | `df2 = df.copy()` | 复印一张表 | 防止改原表 | 不加就是同一张表 |
| `.sort_values()` | `df.sort_values("日期")` | 排序 | 按时间处理 | 多列排序要传列表 |
| `.groupby()` | `df.groupby("代码")` | 分组 | 每只股票单独算 | 后面还要接操作 |
| `.rolling()` | `df["close"].rolling(7)` | 开一个滑动窗口 | 算均线 | 前面几行是 NaN |
| `.mean()` | `.mean()` | 求平均 | 均线 | 空值会让结果变 NaN |
| `.shift()` | `df["涨停"].shift(1)` | 整列往下挪一行 | 拿昨天的值 | 不 shift 会用今天 |
| `.notna()` | `df["M7"].notna()` | 这一行不是空值 | 过滤 NaN | 空值参与条件会变 False |
| `.astype()` | `df["信号"].astype(int)` | True / False 变 1 / 0 | 统计信号数 | 不加也能跑 |
| `.iterrows()` | `for _, row in df.iterrows():` | 一行一行遍历 | 逐笔回测 | 大表很慢 |
| `.iloc[]` | `df.iloc[0]` | 按位置取行 | 取第一行、最后一行 | 位置从 0 开始 |
| `.empty` | `if df.empty:` | 表格是不是空的 | 没数据就跳过 | 不是函数，没有括号 |
| `.sum()` | `df["信号"].sum()` | 求和 | 数信号总数 | 布尔值求和等于 True 的个数 |

## 怎么看长代码

看到长代码不要慌，把它拆成一个个单语法：

```python
df.groupby("证券代码")["close"].transform(...)
```

拆开就是：`groupby` 分组，`["close"]` 取列，`.transform` 对每组做计算。三步都是上面的单语法。
