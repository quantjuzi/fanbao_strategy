# broker.py 3天速成卡片

## 总原则

- broker.py 吃透：能口算、能讲清，面试常考。
- 其他模块读通：看代码能讲清流程和为什么，不用每行懂、不用填 TODO。

## 第1天：读翻译，不写代码（1~1.5小时）

- 只看 `broker_逐行翻译.md`。
- 标准：随便指一行，能说出它在干嘛。
- 不求背住，只求"看着不慌"。

## 第2天：只学3个核心计算（1~1.5小时）

1. 佣金：成交额 x 万2.5，和 5 元比，取大的。
   - 1万 -> 2.5元，不够5元 -> 扣5元
   - 30万 -> 75元
2. 滑点：买入价 = 参考价 x (1 + 滑点)，卖出价 = 参考价 x (1 - 滑点)。
3. 净盈亏：毛利润 - 全部费用（佣金 + 过户费 + 卖出印花税）。

## 第3天：填空 + 跑测试（1~1.5小时）

- 把 broker.py 的 TODO 一个个填完。
- 每填一个就运行：
  `tests/test_broker.py`
- 验收：能讲清"一买一卖到底扣多少钱"。

## 面试讲法（30秒版）

"这份代码是A股交易成本计算器：配置类定费率，Broker类算滑点成交价和佣金，最后拼出往返手续费和净盈亏。A股规则是买入无印花税、卖出有，佣金最低5元。"

## 常见坑（讲课时加分）

- 买入绝对没有印花税。
- 佣金有最低5元，过户费没有。
- 算利润必须用滑点后的成交价，不能用参考价。
- 构造函数不要写 `config=BrokerConfig()`，会多个实例共用同一个配置。
