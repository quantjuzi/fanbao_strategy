# Python 基础单词卡（交易版）

用途：读代码时忘了就查，不用背。真正常用的只有 20 个左右，看多了自然熟。

## 最常用的 12 个

| 单词 | 意思 | 交易版理解 |
|---|---|---|
| `def` | 定义函数 | "定义一套操作流程"：`def 选股():` |
| `return` | 返回 | "把结果交出来"，不 return 结果就丢了 |
| `class` | 类 | "定义一个模板"，Broker 就是券商模板 |
| `self` | 自己 | "这个对象自己"，`self.config` = 这个券商自己的参数 |
| `import` | 导入 | "引入工具包"，`import pandas as pd` = 把 pandas 拿进来 |
| `if / elif / else` | 如果 / 否则如果 / 否则 | 条件判断：如果成交额大就买，否则跳过 |
| `for ... in ...` | 对每一个...在...里 | 对列表里每一只票做同样操作 |
| `True / False` | 真 / 假 | 条件成立 / 不成立 |
| `and / or / not` | 且 / 或 / 非 | "换手率高 且 成交额大" |
| `None` | 空 | 还没有值 |
| `print()` | 打印 | 输出到屏幕让你看见，不存储 |
| `.append()` | 加进末尾 | 把票放进备选池列表 |

## 数据类型

| 单词 | 意思 | 交易版理解 |
|---|---|---|
| `list` | 列表 | 一串票：`["000001", "000002"]` |
| `dict` | 字典 | 带标签的盒子：`{"code": "000001", "price": 12.5}` |
| `int` | 整数 | 股数 100 |
| `float` | 小数 | 价格 12.50 |
| `str` | 字符串（文字） | 股票代码 "000001" |
| `bool` | 布尔（真/假） | 是否涨停 |
| `len()` | 长度 | 列表里有几只票 |
| `range()` | 范围 | 从 0 到 N 的一串数字 |

## pandas 常用词

| 单词 | 意思 | 交易版理解 |
|---|---|---|
| `DataFrame` | 数据表 | 一张股票日线表 |
| `read_csv()` | 读文件 | 打开 CSV 数据 |
| `head()` | 看前几行 | 先瞄一眼数据长什么样 |
| `sort_values()` | 排序 | 按评分从高到低排 |
| `groupby()` | 分组 | 按股票代码分组，每只票单独算 |
| `shift(-1)` | 上下移动一行 | 拿到"下一行"数据，做 T+1 模拟 |
| `dropna()` | 去掉空值 | 删掉缺数据的行 |
| `mean()` | 平均 | 平均收益 |
| `sum()` | 求和 | 总盈亏 |
