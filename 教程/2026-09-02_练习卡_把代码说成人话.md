## 一、看懂代码的总方法

代码里最常见的一行，长这样：

```python
df["新列名"] = 右边算出来的结果
```

中文读法：**把右边算出来的结果，整列放进表格里，并给它起名叫“新列名”。**

所以看代码时先问三句话：

1. 左边给哪一列起了名字？
2. 右边在算什么？
3. 算完的结果有多少个值？

只要右边是一整列，赋值以后就会变成表格的新列。

---

## 二、逐行拆：rolling 均线

```python
df["M7"] = df["收盘"].rolling(7).mean()
```

从左往右拆：

- `df["收盘"]`：拿出收盘价这一列
- `.rolling(7)`：从这一列里，每一行都截出一个小窗口，窗口里包括“自己 + 前 6 行”，一共 7 行
- `.mean()`：每个小窗口求平均
- `df["M7"] =`：把每一行算出来的平均值，放到新列 M7 里

中文读法：

> 给表格加一列 M7，每一行的值，是这行以及之前 6 行收盘价的平均值。

举例，假设某天附近收盘价是：

| 日期 | 收盘 |
|---|---:|
| 第1天 | 10.0 |
| 第2天 | 10.2 |
| 第3天 | 10.1 |
| 第4天 | 10.3 |
| 第5天 | 10.0 |
| 第6天 | 10.2 |
| 第7天 | 10.4 |

第 7 天的 M7 = (10.0 + 10.2 + 10.1 + 10.3 + 10.0 + 10.2 + 10.4) ÷ 7

注意：第 1 天只有自己 1 行，`rolling(7)` 默认算不出来，会变成空值 NaN。这就是模板里要 `fillna` 的原因。

---

## 三、逐行拆：M7 比 M20 高 5%

先算两条均线：

```python
df["M7"] = df["收盘"].rolling(7).mean()
df["M20"] = df["收盘"].rolling(20).mean()
```

再写条件：

```python
df["M7强"] = df["M7"] / df["M20"] > 1.05
```

拆开看：

- `df["M7"] / df["M20"]`：每一行都用当天的 M7 除以 M20
- `> 1.05`：算完以后和 1.05 比较
- 比较的结果不是数字，而是 True（成立）或 False（不成立）
- `df["M7强"] =`：把这列 True / False 存进表格

中文读法：

> M7 比 M20 高 5% 以上的行，M7强这一列记 True，否则记 False。

手算核对：

| M7 | M20 | M7 ÷ M20 | 是否 > 1.05 |
|---|---:|---:|---|
| 10.2 | 10.0 | 1.02 | False |
| 10.6 | 10.0 | 1.06 | True |

---

## 四、逐行拆：两个条件同时满足

```python
df["候选"] = (df["M7强"] == True) & (df["成交额"] > 8e8)
```

说明：

- 第一个括号是一组判断，结果是 True / False
- 第二个括号是另一组判断，结果也是 True / False
- `&` 读作“并且”
- 只有两边都是 True，这一行结果才是 True；有一个 False，就是 False

中文读法：

> 一只股票今天 M7 强，而且成交额超过 8 亿，候选记 True，否则记 False。

`8e8` 是一个大数的写法：

- 8 亿 = 800,000,000
- Python 科学计数法：`1e8` = 100,000,000
- 所以 `8e8` = 800,000,000

用表格验证：

| M7强 | 成交额 | 结果 |
|---|---:|---|
| False | 9亿 | False，因为 M7 不满足 |
| True | 7亿 | False，因为成交额不满足 |
| True | 9亿 | True，两个都满足 |

## 五、逐行拆：竞价涨幅

```python
df["竞价涨幅"] = df["开盘"] / df["昨收"] - 1
```

拆开看：

- `df["开盘"]`：当天 9:25 集合竞价开出的价格
- `df["昨收"]`：前一个交易日收盘价，数据里常叫 pre_close
- 除出来是“开盘价是昨收的几倍”
- 减 1 以后，大于 0 就是高开，等于 0 是平开，小于 0 是低开

中文读法：

> 每行算一次：开盘价比昨收高多少。正数就是竞价高开。

手算：

- 昨收 10.00，开盘 10.15
- 10.15 ÷ 10.00 = 1.015
- 减 1 以后 = 0.015，也就是高开 1.5%

注意：这是“当天自己的竞价”。你的策略里说“昨日竞价”，指的是表格里 T-1 那一行算出来的值。

---

## 六、逐行拆：实体涨幅

```python
df["实体涨幅"] = (df["收盘"] - df["开盘"]) / df["昨收"]
```

拆开看：

- `收盘 - 开盘`：算 K 线实体有多长
- 除以昨收：把实体长度换成“涨了昨收的百分之几”
- 上下影线不算，只看实体

中文读法：

> 每一行算一次：实体部分相对昨收涨了多少。

手算：

- 昨收 10.00，开盘 10.15，收盘 10.45
- 实体 = 10.45 - 10.15 = 0.30
- 实体涨幅 = 0.30 ÷ 10.00 = 3%

如果你希望数字显示成“3%”而不是“0.03”，最后可以乘 100：

```python
df["实体涨幅%"] = (df["收盘"] - df["开盘"]) / df["昨收"] * 100
```

---

## 七、逐行拆：有没有涨停

```python
df["涨停"] = df["收盘"] >= df["涨停价"]
```

拆开看：

- `df["涨停价"]`：数据源算好的当日涨停价，不要自己用“涨了 10%”去猜
- `收盘 >= 涨停价`：等于或封在涨停价上都算涨停
- 结果是 True / False

中文读法：

> 当天收盘价碰到涨停价，这一行记 True，否则记 False。

为什么不能只看涨幅：ST 股是 5% 涨跌幅，创业板、科创板是 20%，主板才是 10%，不同股票规则不一样。数据里有涨停价，直接用最稳。

---

## 八、逐行拆：近 10 天有没有涨停过

单只股票时：

```python
df["近10天涨停"] = df["涨停"].rolling(10, min_periods=1).max().astype(bool)
```

拆开看：

- `df["涨停"]`：一列 True / False
- `.rolling(10, min_periods=1)`：每行往前看 10 天；不够 10 天时有多少算多少
- `.max()`：10 天窗口里只要出现过一次 True（相当于 1），结果就是 1
- `.astype(bool)`：把 1 变 True、0 变 False，好看也好用

中文读法：

> 从今天往前数 10 天，只要有一天涨停过，这行就记 True。

注意：多只股票堆在一张表里时不能直接这样 rolling，否则会把上一只股票的涨停算到下一只头上。要先按股票代码分组。这一版先知道“为什么”，等数据真的变成多只股票再补写法。

## 九、逐行拆：昨日涨停

```python
df["昨日涨停"] = df["涨停"].shift(1)
```

拆开看：

- `shift(1)` 不做加减法，它是“把整列往下挪一行”
- 每一行拿到的是上一行原来的值
- 表格第一行没有上一行，得到 NaN（空值）

举例：

| 行 | 涨停 | 昨日涨停 |
|---:|---|---|
| 1 | False | NaN |
| 2 | True | False |
| 3 | False | True |

中文读法：

> 新增一列，每一行记的是它上一行有没有涨停。

你的策略 T-1 选股、T 日买入，心里要有一根时间轴：T-1 是产生信号的那一行，买入发生在它的下一行，而不是同一行。

## 十三、怎样把一整张表“读”下来

策略代码处理的东西，本质上是一张很大的表：

| 日期 | 代码 | 开盘 | 收盘 | 昨收 | 成交额 | 涨停价 |
|---|---:|---:|---:|---:|---:|---:|
| 2026-08-01 | 000001 | 10.00 | 10.45 | 10.00 | 9亿 | 11.00 |

每个函数做的事情，基本都是给这张表“加一列”。

所以读代码时，把这段流程说成人话：

> 每天收盘后生成一张全市场日线表；然后一列一列加：均线、竞价涨幅、实体涨幅、是否涨停；每一列都变成 True 或 False；最后把同时满足条件的行挑出来，就是候选。

不要上来就盯着函数内部看，先看它给表加的是哪一列。

## 十四、条件列算完以后怎么用

你已经生成了 True / False 列，例如：

```python
df["候选"] = (df["M7"] / df["M20"] > 1.05) & (df["成交额"] > 8e8)
```

想数一数今天有几只满足：

```python
df["候选"].sum()
```

为什么 `sum()` 能数 True？因为 Python 里 True 等于 1，False 等于 0，加起来就是满足条件的行数。

想只看满足条件的股票：

```python
df[df["候选"]]
```

中文读法：

> 从表里挑出候选列为 True 的那些行，生成一张小表。

这个写法很常见，括号里的 `df["候选"]` 是筛选条件，外面的 `df[...]` 是按条件取行。

常见错误是写 `if df["候选"]:`，会报错。因为 `df["候选"]` 是一整列（很多个值），不是单一的一个 True / False，不能直接塞进 `if`。

## 十五、最容易说错的三句话

第一句：“rolling 是把以前的数据平均一下。”

更准确的说法：`rolling(7)` 从当前行往前开一个 7 行小窗口，`.mean()` 求这个窗口的平均。

第二句：“shift 是预测明天。”

不对。`shift(1)` 是把昨天的值搬过来，拿到的都是已经发生的数据，不包含任何未来信息。

第三句：“当天选股，当天就能买。”

不对。日线收盘数据收盘后才有，所以你的流程是 T-1 收盘选股、T 日买入。当天收盘才知道信号，当天已经买不进了。

### 17.1 文件开头：请工具包

```python
import numpy as np
import pandas as pd
from dataclasses import dataclass
```

人话：

- `import` = 把别人写好的工具包请进来
- `import numpy as np` = 把 numpy 请进来，以后用 `np` 两个字代表它
- `import pandas as pd` = 把 pandas 请进来，以后用 `pd` 代表它
- `from dataclasses import dataclass` = 从 dataclasses 这个包里，只拿 dataclass 这一个工具

看见代码里的 `np`、`pd`，心里读“numpy 工具”“pandas 工具”就行。

### 17.2 配置类：一张写满参数的配置单

```python
@dataclass(frozen=True)
class TradeConfig:
    initial_cash: float = 100_000.0
    commission_rate: float = 0.00025
```

人话：

- `class` = 我要定义一种新东西，这里叫 TradeConfig
- `@dataclass` = 自动帮你生成初始化函数，不用手写 `self.xxx = xxx`
- `frozen=True` = 创建好以后，里面的参数不许再改
- `initial_cash: float = 100_000.0` = 有个参数叫初始资金，类型是小数，默认 10 万
- `100_000.0` 里的下划线只是给人看的，等于 100000

读成一句：

> 这张配置单里写着：初始资金 10 万，手续费万 2.5，建好以后参数锁死。

### 17.3 造数据：没有真实行情时先造一张假表

```python
rng = np.random.default_rng(0)
prices = 10 + np.cumsum(rng.normal(0, 0.3, days))
```

人话：

- `rng` = 随机数生成器
- `default_rng(0)` = 随机种子固定成 0，这样每次运行产生的“随机”数据都一样，方便核对
- `rng.normal(0, 0.3, days)` = 生成一堆小波动，平均值 0，波动大小 0.3
- `np.cumsum(...)` = 把波动一个个累加起来，形成一条上下走的价格曲线
- `10 + ...` = 从 10 元附近开始走

`np.cumsum` 这个名字可以拆着记：`cum` = 累计，`sum` = 求和，连起来就是累计相加。

```python
df = pd.DataFrame({
    "日期": pd.date_range("2026-01-01", periods=days, freq="D"),
    "收盘": prices,
})
```

人话：

> 用字典生成一张表：日期列从 2026-01-01 开始，一共 days 天；收盘价列放刚算出来的价格。

`pd.date_range` = 生成一串连续的日期。

### 17.5 先复印，再改表

人话：

### 17.6 把一段条件变成一整列

```python
df["候选"] = (df["M7"] / df["M20"] > 1.05) & (df["成交额"] > 8e8)
```

人话：

### 17.7 判断涨停和昨天涨停

```python
df["涨停"] = df["收盘"] >= df["涨停价"]
df["昨日涨停"] = df["涨停"].shift(1)
```

人话：

> 先问每行：今天收盘碰到涨停价没有？答案是 True 或 False，放进涨停列。

### 17.8 手续费：买卖费用不一样

```python
def buy_fee(amount: float, cfg: TradeConfig) -> float:
    """买入费用 = 成交额 x 佣金，最少5元。没有印花税。"""
    return max(amount * cfg.commission_rate, cfg.min_commission)
```

人话：

> 买入手续费，等于成交额乘佣金费率；如果算出来不到 5 元，就按最低 5 元收。

`max(A, B)` = 在 A 和 B 里取大的那个。

```python
def sell_fee(amount: float, cfg: TradeConfig) -> float:
    """卖出费用 = 佣金 + 印花税。卖出才交印花税。"""
    commission = max(amount * cfg.commission_rate, cfg.min_commission)
    return commission + amount * cfg.stamp_duty_rate
```

人话：

> 卖出费用先按同一个规则算佣金，再加印花税；买入没有印花税，卖出才有。

### 17.9 回测主循环：一天一天看

for i, row in df.iterrows():
```

人话：

> 从表格第一行开始，一行一行看；i 是第几行，row 是这一行的所有数据。

`iterrows` 可以拆着记：iterate = 遍历，rows = 行，连起来就是“逐行遍历”。

if row["金叉"] and shares == 0 and i < len(df) - 1:
```

人话：

> 如果这一行出现买入信号，而且我现在空仓，而且今天不是最后一天，就准备买入。

为什么不是最后一天买：最后一天买完没法在回测里卖出，盈亏算不完。

人话：

`int(...)` = 把结果截成整数，不要小数，因为股票按手买卖。

### 17.11 回测结束强制清仓

```python
if shares > 0:
    last = df.iloc[-1]
```

人话：

> 回测跑完如果手里还拿着股票，就用最后一行收盘价强制卖掉，不然这笔持仓的盈亏永远算不完。

`df.iloc[-1]` = 取表格最后一行；`-1` 在 Python 里表示倒数第一个。

### 17.12 绩效统计

```python
wins = (trades["盈亏"] > 0).sum()
win_rate = wins / len(trades) * 100
```

人话：

> 先把每笔盈亏大于 0 的行标成 True，再数有多少个 True，得到盈利笔数；盈利笔数除以总笔数，就是胜率。

```python
peak = equity["总资产"].cummax()
drawdown = equity["总资产"] / peak - 1
max_drawdown = drawdown.min() * 100
```

人话：

> 每天算一遍“今天资产比起历史最高点少了多少”，这些值里最小的那个，就是最惨时的回撤。

`cummax` = 累计最大值，也就是到目前为止的最高点。

### 17.13 打印结果

人话：

`f` 开头的字符串叫 f-string，大括号里可以直接放变量。

## 十八、把回测的买卖流程说成人话

整个模板的逻辑，用一句话讲就是：

> 每天开盘前看昨天的信号，有金叉就全仓买入，有死叉就全仓卖出；买卖都按实际价格加减滑点，再扣手续费；最后把每一笔盈亏汇总成胜率和回撤。

你以后改成趋势高开策略时，只需要把“金叉、死叉”这两个信号，换成你自己的条件。买卖执行、手续费、绩效统计这些骨架都可以先不动。

这也是为什么让你从模板改起，而不是从零写：你已经看懂的模板，就是你的第一版框架。
