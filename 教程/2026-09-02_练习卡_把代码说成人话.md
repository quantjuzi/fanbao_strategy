## 一、口头翻译

看见下面每行代码，就用中文念出来：

```python
df["M7"] = df["收盘"].rolling(7).mean()
```

念法：给表格加一列 M7，每行是最近 7 天收盘价平均值。

```python
df["候选"] = (df["M7"] / df["M20"] > 1.05) & (df["成交额"] > 8e8)
```

念法：M7 比 M20 高 5% 以上，而且当天成交额超过 8 亿，才算候选。

```python
df["昨日涨停"] = df["涨停"].shift(1)
```

念法：新增一列，每行取上一行是不是涨停。

```python
df["竞价涨幅"] = df["开盘"] / df["昨收"] - 1
```

念法：当天开盘价比昨天收盘高多少，就是竞价涨幅。

## 三、判断正误

1. `df.copy()` 是复印一张表，原表不会被动。对
2. rolling 开头几天算不出值，不处理直接回测也没事。错，会带着空值算错
3. 买入费用里有印花税。错，印花税只在卖出收

## 四、手算

假设某只股票：

- T-2 收盘：10.00
- T-1 开盘：10.15
- T-1 收盘：10.45

算：

1. T-1 竞价涨幅 = ?
2. T-1 实体涨幅 = ?

参考答案：

1. `10.15 / 10.00 - 1 = 1.5%`
2. `(10.45 - 10.15) / 10.00 = 3.0%`
