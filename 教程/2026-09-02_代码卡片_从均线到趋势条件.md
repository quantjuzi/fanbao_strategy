# 2026-09-02 代码卡片：从均线模板到趋势条件

> 配套文件：`迷你均线练习v2.py`
>
> 用法：先在模板里找到对应段落，再读这张卡，最后把“读法”念出来。

## 1. 加一列：rolling 是“窗口平均”

```python
df["M7"] = df["收盘"].rolling(7).mean()
```

读法：给表格加一列 M7，值是最近 7 天收盘价平均值。

拆开看：

- `rolling(7)`：从当前行往前看，把“自己 + 前 6 行”合成一个小窗口
- `.mean()`：对这个窗口求平均
- `df["M7"] =`：把算出来的整列放回原表，新列名叫 M7

你要写的 M7/M20 就是：

```python
df["M20"] = df["收盘"].rolling(20).mean()
df["M7强"] = df["M7"] / df["M20"] > 1.05
```

## 2. 两个条件同时满足：`&` 是“并且”

```python
df["候选"] = (df["M7"] / df["M20"] > 1.05) & (df["成交额"] > 8e8)
```

- 括号必须写，`&` 两边各是一个完整判断
- `&` = 并且，两个都是 True，结果才是 True
- `8e8` = 8 亿，因为 `1e8 = 100000000`
- 这一行跑完后，`候选` 列只有 True / False

## 3. 竞价涨幅：用“开盘 / 昨收”

```python
df["竞价涨幅"] = df["开盘"] / df["昨收"] - 1
```

- A股日线里的 `开盘`，就是 9:25 集合竞价开出来的价格
- 结果大于 0 表示这天的竞价高开
- 如果策略说的是“昨日竞价”，就取 T-1 那行的同一个公式，不用另写一套

## 4. 实体涨幅：只算 K 线实体

```python
df["实体涨幅"] = (df["收盘"] - df["开盘"]) / df["昨收"]
```

- K 线实体 = 收盘 - 开盘，上下影线不算
- 分母用昨收，别用开盘，否则含义就变了

“当日没涨停”不要靠涨幅猜，直接用涨停价：

```python
df["涨停"] = df["收盘"] >= df["涨停价"]
```

## 5. 近 10 天涨停过：rolling 求最大值

单只股票时这样写：

```python
df["近10天涨停"] = df["涨停"].rolling(10, min_periods=1).max().astype(bool)
```

- `涨停` 列里 True 相当于 1，False 相当于 0
- `max()` 就是在 10 天窗口里看有没有出现过 1
- `min_periods=1`：前面不足 10 天也照样算，不丢行
- 多只股票不能直接这样 rolling，要先按股票分组；现在先知道原因，不用急着记代码

## 6. shift(1)：把整列往下挪一行

```python
df["昨日涨停"] = df["涨停"].shift(1)
```

- `shift(1)` 让每一行拿到“上一行”的值
- 第一行没有上一行，会变成空值 NaN

你的策略是 T-1 选股、T 日买入，所以思维顺序是：信号行 = T-1，买入行 = 表格里往下的下一行。

## 7. 改模板时只动哪里

1. 在 `add_signals` 函数里加新列
2. `run_backtest` 是买卖执行，第一轮先不改
3. 前面滚动算不出来的行会变空，记得用 `fillna(False)` 或删掉
4. 一次只加一个条件，跑一次，别一口气加五个

## 8. “昨天”到底取哪一行

你的策略是 T-1 选股、T 日买入，时间轴是：

```text
T-2 收盘 -> T-1 选股 -> T 日买入
```

代码里最容易绕晕的就是“昨天”这个词。先定死两句话：

- 如果你的条件说的是“选股日当天”，就用这一行自己的数据，不用挪
- 如果你的条件说的是“选股日的前一天”，才需要 `shift(1)`

例如你的五个条件都发生在 T-1 当天：

```python
df["竞价涨幅"] = df["开盘"] / df["昨收"] - 1      # T-1 当天竞价
df["实体涨幅"] = (df["收盘"] - df["开盘"]) / df["昨收"]  # T-1 当天实体
df["涨停"] = df["收盘"] >= df["涨停价"]            # T-1 当天是否涨停
```

这些用的都是本行数据，不需要再 shift。只有“10 天前有没有涨停过”这种要往前看的条件，才用 rolling。

T 日买入价怎么处理：回测时从同一只股票里找到 T-1 的下一行，取下一行的开盘价。不要把下一行数据提前拿来做信号，那就是未来函数。

## 9. 成交额的单位先定死

数据来源不同，成交额单位可能是：

- 元：8 亿写成 `8e8` 或 `800000000`
- 万元：8 亿写成 `800000`
- 亿元：8 亿就是 `8`

写条件前，先 `print(df["成交额"].head())` 看几个数。如果看到 `800000000` 这种九位数，就是元；看到 `800000`，就是万元。

最容易犯的错：数据明明单位是万元，却拿 `8e8` 去比，导致几乎没有股票满足。

## 10. 算不出来的空值要处理

滚动均线、shift 都会制造空值：

```python
df["M7"] = df["收盘"].rolling(7).mean()      # 前 6 行是空
df["昨日涨停"] = df["涨停"].shift(1)          # 第一行是空
```

处理办法：

```python
df["昨日涨停"] = df["昨日涨停"].fillna(False)  # 空值填 False
```

为什么填 False：没有昨天，就当成“昨天没涨停”，不产生信号，逻辑上说得通。

如果你不确定哪里有空值，先打印：

```python
print(df.isna().sum())
```

中文读法：

> 数一数每一列有多少个空值。

## 11. 加完条件怎么验证

只加一个条件后，别急着回测，先回答三个问题：

```python
df["候选"].sum()        # 一共有多少行满足
df[df["候选"]].head(10) # 看看满足的是哪些行
df["候选"].tail(20)     # 最近 20 天信号有没有异常集中
```

人话：

- `.sum()`：数出候选列有多少个 True
- `df[df["候选"]]`：只留下候选是 True 的行
- `.head(10)`：看前 10 行
- `.tail(20)`：看最后 20 行

如果最近 20 天每天都有信号，说明条件太松；如果几个月一次信号都没有，说明条件太严。先用肉眼确认，再谈优化。
