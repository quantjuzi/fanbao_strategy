# 研究脚本

这里保存因子分组、样本筛选、分钟数据处理和结果导出脚本。不同实验的代码会保留当时的处理方式，重点是复现统计口径，不追求把它们统一成一个框架。

2026 反包因子研究的完整复现代码见
[反包策略研究_2026.py](./反包策略研究_2026.py)。该脚本只包含历史研究流程和
当年公开策略条件，不包含 2026-10-08 之后当前实盘使用的核心规则。

如果你想快速更换因子做分组研究，使用结构更简单的
[反包因子研究_通用版.py](./反包因子研究_通用版.py)：

```bash
python 脚本/反包因子研究_通用版.py --factor 成交额_亿
```

核心策略实现放在 [回测/高开均线回测.py](../回测/高开均线回测.py)，包含数据清洗、信号生成、买卖对齐、交易成本、组合选择和绩效统计。
