# 新策略实盘

## 开场

2026-10-08 开始，用一套新的短线策略做实盘验证。

这套策略不是单点信号，而是围绕涨停后的分歧与修复，分成三个交易模式。
每个模式都有自己的样本条件、过滤因子和优先级，核心参数来自前期回测和
因子分组研究，不在公开仓库展开。

实盘记录公开三件事：模式分类、买卖执行、账户结果。
策略核心、筛选条件和参数区间保留在本地，不随仓库公开。

## 三个模式

### 单涨停炸板

首板涨停后次日炸板，观察断板后的承接，择机参与修复。

### 连板断板

连板股断板后，观察分歧转一致的机会，做次日反包。

### 连板炸板

连板股盘中炸板后，观察回封或承接强度，择机参与。

三个模式同日出现时，按优先级和盘面强度选择，每天最多 4 只。

## 执行口径

- 初始资金：80,000 元
- 每笔金额：20,000 元
- 每天最多：4 只
- 买入：信号确认后 T+1 开盘
- 卖出：T+2 均价

## 为什么不公开策略核心

这里不展开样本条件、过滤因子、参数区间和优先级规则，原因有几点：

1. 这些内容来自个人前期研究和数据验证，属于策略本身，不是实盘记录的展示重点。
2. 策略仍在实盘验证阶段，现有参数来自样本内研究，还没有经过完整样本外和长期实盘检验，过早公开容易被当成现成结论。
3. 具体因子和阈值一旦公开，容易被直接复制，交易信号同质化后会增加拥挤和滑点，反而削弱策略的实际效果。
4. 实盘记录要展示的是执行纪律、买卖记录、账户结果和复盘过程，不是提供一套可以直接照做的交易配方。
5. 公开具体的进出场条件，容易被当成投资建议，也会带来事后解读。这里只保留模式分类和结果，避免误导。
6. 短线策略对盘面和情绪变化敏感，规则需要持续调整，固定参数版本不能代表策略的全貌。

因此，公开范围只到模式名称、执行口径和实盘结果，策略核心保留在本地。
