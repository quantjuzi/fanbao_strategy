# 新策略实盘

## 开场

2026-10-08 开始，用一套新的短线策略做实盘验证。

过去一年的实盘成交、费用和盈亏已经去掉个人信息整理好，可以在仓库其他位置查看：

- [实盘交易记录](../README.md#实盘交易记录)
- [实盘成交明细](../结果/实盘成交明细.csv)

每笔金额 10,000 到 20,000 元。

这套策略不是单点信号，而是围绕涨停后的分歧与修复，分成两个交易模式。
每个模式都有自己的样本条件、过滤因子和优先级，核心参数来自前期回测和
因子分组研究，不在公开仓库展开。

实盘记录公开三件事：模式分类、买卖执行、账户结果。
策略核心、筛选条件和参数区间保留在本地，不随仓库公开。

## 两个模式

### 单板反包

首板后断板，观察断板后的承接和修复，做次日反包。

### 连板反包

连板后断板，观察分歧转一致的机会，做次日反包。

两个模式同日出现时，按优先级选择，每天最多 6 只。

## 关于连板接力

原本考虑把连板接力也纳入这一轮实盘，但回测显示这个模式的波动率偏大，
平均盈利和平均亏损都比较大，单笔结果不够稳定。

为了保证执行纪律和资金曲线可控，暂时不加入连板接力，先做实盘验证
单板反包、连板反包这两个模式。后续如果样本外验证和实盘
表现更稳定，再考虑是否加入。

## 执行口径

- 每笔金额：10,000 到 20,000 元
- 每天最多：6 只
- 买入：信号确认后 T+1 竞价直接买入
- 卖出：不涨停就 T+2 盘中卖出，涨停再根据情况卖出

## 执行纪律

- 买入以 T+1 竞价为主，按候选顺序执行。
- 盘中可以低吸，不追拉升。
- 即使判断大盘情绪在好转，也不追高。
- 不因为盘中的临时变化改变原计划。
- 计划外操作要单独记原因和结果，方便复盘。

## 为什么不公开策略核心

这里不展开样本条件、过滤因子、参数区间和优先级规则，原因有几点：

1. 短线股的走势与题材、情绪密切相关，这部分无法用代码完整量化。代码只负责按条件筛出候选股票，真正是否买入、买多少，还要结合信号日的题材强弱、板块共振和短线情绪，由主观分析主导。
2. 这些内容来自个人前期研究和数据验证，属于策略本身，不是实盘记录的展示重点。
3. 策略仍在实盘验证阶段，现有参数来自样本内研究，还没有经过完整样本外和长期实盘检验，过早公开容易被当成现成结论。
4. 实盘记录要展示的是执行纪律、买卖记录、账户结果和复盘过程，不是提供一套可以直接照做的交易配方。
5. 公开具体的进出场条件，容易被当成投资建议，也会带来事后解读。这里只保留模式分类和结果，避免误导。
6. 短线策略的规则需要随盘面和情绪变化持续调整，固定参数版本不能代表策略的全貌。

因此，公开范围只到模式名称、执行口径和实盘结果，策略核心保留在本地。

## 每日记录

- 成交、持仓、账户每天记，这是数据。
- 复盘不用写长，记最值得记的一件事就够。
- 没操作、没信号的日子，写一行就行，不用凑内容。

## 候选跟踪口径

每天更新的候选表现，统一按这个口径算，买入价和卖出价分开取：

| 情况 | 买入价 | 卖出价 |
| --- | --- | --- |
| **没买的候选**（只做纸上跟踪） | 信号日次日**竞价价** | **第二日成交均价** |
| **真买了的候选** | **实际成交价** | **实际卖出价** |

也就是说：没买的按“竞价买、第二日均价卖”模拟，买了的就用账户里的真实成交价，
两套不混。候选表现表里会标明每一行是“已买”还是“未买”，避免看混。
