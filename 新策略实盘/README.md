# 新策略实盘

## 开场

2026-10-08 开始，用一套新的短线策略做实盘验证。

这套策略不是单点信号，而是围绕涨停后的分歧与修复，分成三个交易模式。
每个模式都有自己的样本条件、过滤因子和优先级，核心参数来自前期回测和
因子分组研究，不在公开仓库展开。

实盘记录公开三件事：模式分类、买卖执行、账户结果。
策略核心、筛选条件和参数区间保留在本地，不随仓库公开。

## 三个模式

### 单涨停炸板

首板涨停后次日炸板，观察断板后的承接，择机参与修复。

### 连板断板

连板股断板后，观察分歧转一致的机会，做次日反包。

### 连板炸板

连板股盘中炸板后，观察回封或承接强度，择机参与。

三个模式同日出现时，按优先级和盘面强度选择，每天最多 4 只。

## 执行口径

- 初始资金：80,000 元
- 每笔金额：20,000 元
- 每天最多：4 只
- 买入：信号确认后 T+1 开盘
- 卖出：T+2 均价

## 为什么不公开策略核心

样本定义、过滤因子、参数区间和优先级规则来自个人研究，属于策略本身。
实盘记录展示的是执行过程和结果，不是策略配方，所以核心部分不在这里展开。

## 每日记录

- 每天复制 `每日记录模板.md`，重命名为 `YYYY-MM-DD.md`。
- 每天收盘后更新 `资金与持仓.md`。

## 说明

实盘记录只用于复盘和展示执行过程，不构成投资建议。
历史回测不代表未来收益。
