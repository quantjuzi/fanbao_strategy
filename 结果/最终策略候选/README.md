# 最终策略候选

研究区间：2025-10-01 至 2026-09-30，共 241 个交易日。
反包、二连板和单板反包分别保留三项候选。
所有收益和资金占用统一按全年区间计算。

**收益率口径**：所有收益率都按资金加权算（净盈亏 ÷ 买入金额）。
回测里每笔固定 2 万元等额买入，所以它和每笔等权平均是同一个数。

当前优先复核：[反包 142 版每日前三](./反包142每日前三_股票明细.md)。
