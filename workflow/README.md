# 量化策略教学工作流

## 这个 workflow 是干什么的

这个目录不是给你"自动运行"用的，是一套手把手教学路线——教你怎么把一套主观A股短线策略，一步一步转化成可以回测的量化代码。

整个过程是**半手动**的：你跟着 notebook 的思路走，每跑完一段代码就停下来看结果，理解为什么这么写，而不是无脑执行完就扔。

## 和项目其他目录是什么关系

```
项目根目录/
├── workflow/          ← 你在这里：7步教学路线
├── backtest/          ← 项目已有的回测引擎，step5会用到
├── data_pipeline/     ← 数据清洗模块（cleaner.py），step2会用到
├── strategies/        ← 策略逻辑代码，step3-4会用到
├── config/            ← 配置文件，step5会用到
├── daily_notes/       ← 你的实盘记录，独立目录不动
└── scripts/           ← 辅助脚本（上传、绩效分析等）
```

**教学的设计思路：** 每个 step notebook 里面调用的是项目已有的模块（而不是重写一遍），这样你学完之后对自己项目每一行代码都心里有数。

## 7 步路线图

| 步骤 | 名称 | 你在学什么 | 依赖 |
|---|---|---|---|
| Step 1 | 环境准备与数据获取 | Python 环境怎么配、数据从哪里来、怎么存 | 无 |
| Step 2 | 数据清洗 | 停牌、ST、复权、脏数据怎么处理 | Step 1 的数据 |
| Step 3 | 因子定义与计算 | 怎么把"反包感觉"变成可计算的指标 | Step 2 的干净数据 |
| Step 4 | 策略筛选逻辑 | 怎么把多个因子组合成买入信号 | Step 3 的因子数据 |
| Step 5 | 回测执行 | 手续费、滑点、仓位管理怎么加进回测 | Step 4 的信号 |
| Step 6 | 绩效分析与指标计算 | 胜率、夏普、最大回撤——这些数告诉你什么 | Step 5 的回测结果 |
| Step 7 | 参数优化与敏感性分析 | 怎么调参数才不是过拟合、哪些因子真正有用 | Step 6 的数据 |

> ⚠️ **新手提醒：** 别一口气跑完 7 步。每做完一步，对照输出检查一下数据是不是你预期的。大部分坑都在第二步和第五步，这两步多花点时间。

## 怎么用

1. `pip install -r ../requirements.txt` 装依赖
2. 打开 Jupyter Notebook 或 VS Code，打开 `step1_环境准备与数据获取.ipynb`
3. 每看完一段 Markdown 再执行代码，看完代码结果再往后走
4. 如果卡住了，回看这一步的"常见坑"和"我的理解"两个部分
5. 做完了看下一步的"输入"说明，确保上一步的产出已经就位

## 一些学习心态

- 不要追求"跑通就行"——每段代码你都要能用自己的话解释它在干什么
- 标注了"常见坑"的地方，都是我实盘踩过的，先看再动手
- 做完全部 7 步之后，你应该能自己给另一个人的策略写一套回测了
