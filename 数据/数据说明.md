# 数据目录

原始行情和分钟数据体积较大，**不进入公开仓库**，只保留在本地。

本仓库的研究只用 2026-01-01 至 2026-09-30 的日线区间。
当前脚本默认读取 `数据/聚宽因子_2026-01-01_2026-09-30.csv`。

## 生成标准化文件

1. 在 `数据/` 下新建 `原始/` 目录。
2. 把聚宽导出的 `聚宽实盘分类日线_*.csv` 放入该目录。
3. 运行：

```bash
python 脚本/生成全年因子数据.py
```

如果原始文件不在默认目录，也可以通过环境变量或参数指定：

```bash
python 脚本/生成全年因子数据.py "D:/行情数据"
```

如果原始文件已经包含研究期前的历史日线，脚本会先用完整历史计算 M7、M14，
再截取 `2026-01-01` 到 `2026-09-30`，避免研究期开头缺失均线。

也可以指定第二个参数，把结果输出到其他位置：

```bash
python 脚本/生成全年因子数据.py "数据/原始" "work/聚宽因子_2026.csv"
```

生成后的标准文件仍保存在 `数据/` 下，不会被提交到公开仓库。

## 下载原始日线

需要重新下载行情时，可以运行：

```bash
python 脚本/下载日线数据.py --start 2026-07-01 --end 2026-07-31
```

下载结果会保存到 `数据/全市场A股_开始日期_结束日期_baostock.csv`。
