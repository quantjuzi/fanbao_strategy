# 实盘成交明细说明

## 数据来源

数据来自东方财富电子对账单，原始文件只保留在本地，不进入公开仓库。

公开文件为 `结果/实盘成交明细_脱敏.csv` 和 `结果/实盘成交明细_脱敏.xlsx`，只保留股票买入和卖出记录，
不包含姓名、身份证号、资金账号、股东账号、营业部和资金余额。

## 记录范围

- 日期范围：2025-10-13 至 2026-09-30
- 买入记录：715 条
- 卖出记录：648 条
- 合计：1363 条成交记录

## 字段

| 字段 | 说明 |
|---|---|
| 交易日期 | 成交日期 |
| 方向 | 买入或卖出 |
| 证券代码 | 股票代码 |
| 证券名称 | 股票名称 |
| 成交数量 | 股数 |
| 成交价格 | 成交价 |
| 资金发生额 | 买入为负，卖出为正 |
| 成交金额 | 成交金额绝对值 |
| 手续费 | 佣金 |
| 印花税 | 卖出印花税 |
| 过户费 | 过户费 |
| 原始业务类型 | 证券买入或证券卖出 |

## 边界

- 银证转账、银行转证券、证券转银行、利息归本等资金流水已剔除。
- 当前明细还没有标记策略归属，后续需要人工标注反包、连板和新股。
- 这份明细是逐笔成交记录，不是已经配对的买卖回合。
- 计算策略收益时，需要先将买入和卖出配对，并单独处理跨日和未完成交易。

## Excel汇总口径

Excel 的 `汇总` 工作表已经加入：

- 买入和卖出笔数
- 买入和卖出金额
- 手续费、印花税、过户费和总费用
- 按加权平均成本配对的已实现净盈亏
- 账户总盈亏估算

当前对账单计算结果：

- 总费用：18,001.42 元
- 已实现净盈亏：73,095.93 元
- 账户总盈亏估算：45,426.43 元

其中“账户总盈亏估算”按“期末总资产 - 期初现金估算 - 银证净转入”计算。当前有 300 股未匹配卖出，可能来自对账单期初已有持仓，因此账户总盈亏和已实现净盈亏需要继续核对后再作为最终结论。
