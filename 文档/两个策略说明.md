# 两个入选策略

下面两个结果来自代码回测，不包含人工实盘统计，也不把主观题材判断当作回测因子。

卖出价格统一采用卖出日成交均价，并扣除滑点。这个价格是 VWAP 执行基准，不代表人工一定能在均价成交。

汇总数据和导出代码见 [两个策略绩效汇总](../结果/两个策略绩效汇总.csv) 和 [两个策略明细导出脚本](../脚本/导出两个策略交易明细.py)。

## 策略一：连板断板承接

条件：

```text
2连板以上后断板
断板日实体涨幅大于3%
断板日成交额20亿到40亿
次日开盘买入
再次日成交均价卖出
```

| 指标 | 结果 |
|---|---:|
| 交易数 | 67 |
| 净胜率 | 61.19% |
| 平均净收益率 | +2.8072% |
| 平均盈利 | +7.4266% |
| 平均亏损 | -4.4773% |
| 盈亏比 | 1.6587 |
| 按两万元每笔累计盈亏 | +37,616.60 元 |

完整逐笔清单：

- [策略一交易明细 CSV](../结果/策略一_连板断板_交易明细.csv)

## 策略二：单板反包开板2次

条件：

```text
首板后第二日断板
断板日成交额大于6亿
断板日M7/M14大于1
断板日实体涨幅大于1%
涨停日检测到2次开板
次日开盘买入
再次日成交均价卖出
```

| 指标 | 结果 |
|---|---:|
| 交易数 | 87 |
| 净胜率 | 55.17% |
| 平均净收益率 | +1.7405% |
| 平均盈利 | +7.0360% |
| 平均亏损 | -4.7770% |
| 盈亏比 | 1.4729 |
| 按两万元每笔累计盈亏 | +30,285.07 元 |

完整逐笔清单：

- [策略二交易明细 CSV](../结果/策略二_单板反包_交易明细.csv)

## 统一说明

- 两个策略使用同一套交易成本和卖出价格假设
- 开板次数来自 5 分钟线近似判断，不是 Tick/L1/L2 精确数据
- 当前结果来自同一研究区间，暂未做样本外验证
