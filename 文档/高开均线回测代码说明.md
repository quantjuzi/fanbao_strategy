# 高开均线回测代码说明

对应代码：[高开均线回测.py](../回测/高开均线回测.py)

本文按代码顺序解释主要逻辑。方法参数集中管理，数据处理、因子、交易和绩效分开，方便替换成其他策略。

## 1. 文件头和参数：第 1-55 行

文件头说明策略信号和交易规则：

```text
T 日竞价高开
T 日实体涨幅在 -5% 到 5%
T 日收盘价站上 M14
T+1 开盘买入
T+2 成交均价卖出
```

`BacktestConfig` 集中保存可调参数：

- `top_n`：每天最多选几只
- `position_size`：每笔名义资金
- `lot_size`：A 股一手 100 股
- `commission_rate` 和 `min_commission`：佣金
- `stamp_duty_rate`：卖出印花税
- `transfer_fee_rate`：过户费
- `slippage_rate`：买卖滑点
- `min_ma_ratio`：可选的 M7/M14 门槛

这样修改参数时不用在函数内部到处找数字。

## 2. 数据读取和清洗：第 58-116 行

`load_data` 负责：

1. 检查数据文件是否存在
2. 检查必要字段是否齐全
3. 把日期转换成时间类型
4. 把股票代码转换成字符串
5. 把价格、成交量、成交额和均线字段转换成数值
6. 删除空值、停牌、无效价格和无效成交记录
7. 删除同一股票同一天的重复数据
8. 按股票和日期排序

这一层不做策略判断，只保证后面的计算使用干净数据。

## 3. 因子计算：第 119-141 行

`prepare_factors` 计算：

```text
实体涨幅 = close / open - 1
均价 = money / volume
均线比值 = M7 / M14
```

信号条件为：

```text
竞价涨幅 > 0
实体涨幅在 -5 到 5 之间
close > M14
```

如果设置了 `min_ma_ratio`，再增加 M7/M14 过滤。
最终 `信号=1` 表示当天满足条件。

## 4. 对齐 T+1 买入和 T+2 卖出：第 144-169 行

`build_trades` 按股票分组，使用：

```text
shift(-1) -> 下一交易日
shift(-2) -> 再下一交易日
```

对应关系：

- `买入日期`：T+1
- `买入开盘价`：T+1 开盘价
- `卖出日期`：T+2
- `卖出均价`：T+2 成交均价

最后删除无法取得买入价或卖出价的记录，避免使用不存在的未来数据。

## 5. 计算交易成本：第 172-222 行

`apply_costs` 先把参考价转换成可成交价：

- 买入价乘以 `1 + slippage`
- 卖出价乘以 `1 - slippage`

然后按 100 股整手计算能买多少股，再计算：

- 买入金额和卖出金额
- 买卖佣金，低于最低佣金时按最低值
- 过户费
- 卖出印花税
- 净盈亏和净收益率

交易成本在统计前统一扣除，避免用毛收益判断策略。

## 6. 每日组合：第 225-238 行

`select_portfolio` 在每个信号日按成交额降序排名，只保留前 `top_n` 名。

这一步回答“不是所有信号都买，每天实际买哪些”。

## 7. 资金占用：第 241-268 行

`max_concurrent_positions` 按买入日到卖出日计算最高并发持仓数。

例如同一天最多同时持有 6 只股票，如果每只 2 万元，则至少要准备 12 万元周转。这个指标比单纯累计收益更接近实际资金约束。

## 8. 绩效统计：第 271-351 行

`calculate_metrics` 计算：

- 交易数
- 净胜率
- 平均净收益率
- 平均盈利和平均亏损
- 盈亏比
- 总净盈亏
- 最高并发持仓和周转资金
- 区间资金收益率
- 年化收益
- 最大回撤
- 夏普

净值曲线按卖出日收益重新索引到交易日，没有交易的日期补 0，避免只在有交易的日子计算夏普。

## 9. 命令行参数：第 354-381 行

`parse_args` 允许运行时调整：

```text
--top-n
--position-size
--ma-ratio
--output
```

这样可以在不改代码的情况下做参数对比。

## 10. 主流程：第 384 行以后

`main` 按固定顺序执行：

```text
读取数据
-> 计算因子
-> 生成信号
-> 对齐买卖
-> 扣除成本
-> 选择组合
-> 计算绩效
```

这个顺序适用于大多数日线策略。换成其他策略时，只需要替换因子和买卖规则，数据清洗、成本、组合和绩效框架可以复用。
