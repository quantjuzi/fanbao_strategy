# 量化工作流说明

量化研究的核心不是“找到一个看起来厉害的条件”，而是把交易假设拆成可复现、可统计、可验证的步骤。不同策略可以不同，但研究流程基本固定。

## 标准流程

### 1. 明确研究问题

先写清楚要验证什么。例如：

```text
连板断板后，成交额在什么区间时，后续收益更稳定？
```

问题和结论必须对应，不能在看到结果后临时换问题。

### 2. 数据定义和清洗

明确数据来源、字段含义、时间范围和缺失值处理。重点检查：

- 日期和股票代码
- 开高低收、成交量和成交额
- 停牌和异常记录
- 主要字段缺失

### 3. 计算因子

因子必须只能在当时可获得的数据上计算。例如：

- 实体涨幅 = 收盘价 / 开盘价 - 1
- 均线位置 = 收盘价 / M14
- 成交额区间
- 连板数、断板状态、开板次数

因子定义要固定，不能根据结果随意改口径。

### 4. 生成事件和信号

把策略想法转成明确的条件，例如：

```text
前一日涨停 + 当日断板 + 成交额大于某个阈值
```

信号只能在信号日收盘后确认，不能把未来数据提前使用。

### 5. 对齐买卖规则

每个策略都必须明确：

- 哪一天买
- 用什么价格买
- 哪一天卖
- 用什么价格卖

本项目统一按**第二日竞价买入、第三日均价模拟卖出**研究。成交均价是 VWAP 执行基准，并扣除滑点。

### 6. 加入交易成本

不能只看价格差，至少要处理：

- 佣金和最低佣金
- 印花税
- 过户费
- 滑点
- A 股整手交易

### 7. 构建组合和资金约束

信号多不等于都能买。需要检查：

- 每日最多买几个
- 每笔投入多少资金
- 同时持仓占用多少资金
- 资金是否足够周转

### 8. 计算绩效

至少同时看：

- 交易数
- 净胜率
- 平均净收益率
- 平均盈利和平均亏损
- 盈亏比
- 净利润因子
- 最大回撤
- 周转资金和资金收益率

### 9. 单因子验证

每次只改一个因子，其他条件保持不变。对比该因子的不同取值，观察：

- 胜率变化
- 平均收益变化
- 样本量变化
- 盈亏比变化
- 资金效率变化

正向、中性、负向和样本不足都要保留。

### 10. 样本外和稳健性

同一区间表现好不代表未来有效。后续需要：

- 样本外测试
- 参数敏感性检查
- 不同市场环境检查
- 极端涨停和跌停处理
