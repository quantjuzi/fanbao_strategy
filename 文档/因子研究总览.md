# 因子研究总览

研究区间：2026-01-01 至 2026-09-30。
所有回测计入佣金、印花税、过户费和滑点，每笔模拟本金 2 万元。

## 研究流程

1. 从全市场断板样本出发（11,911 笔）
2. 逐级加条件：连板数 → 成交额 → 实体涨幅 → 指数环境
3. 每加一个条件，记录样本数和收益变化，判断因子方向
4. 在合格样本上逐个变换因子，比较分组表现
5. 按样本量、收益和资金占用确定最终策略

| 全市场反包 | 11,911 | 0 | 44.53% | -0.2348% | 0 | 起点 |

| 加：断板日指数 -1% 到 2% | 111 | -31 | 60.36% | +1.5622% | +0.3332 | 正向 |
