## 策略说明

### 反包模式

核心逻辑：选择前一日涨停后断板调整、次日有反包预期的股票进行T+1交易。

**筛选条件：**
1. T-2或T-3日涨停（加分项）
2. T-1日未涨停
3. T-1日成交额 > 15亿
4. 均线多头排列（M7/M14 > 1.0）
5. 实体涨跌幅 > -3%（加分项）

**执行规则：**
- 次日竞价或开盘买入
- T+1按分时图+板块强度+大盘情绪综合判断卖出
- 严格次日卖出纪律，不扛票
