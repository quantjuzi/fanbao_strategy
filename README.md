本项目研究 A 股短线交易中的涨停、连板断板、反包、竞价强弱、成交额和开板行为。重点不是固定一套历史最优参数，而是建立一套可以反复复核的因子比较流程。

研究围绕三个问题展开：

- 连板后断板，哪些量价特征会改善次日开盘买入、第二个交易日成交均价卖出的收益
- 二连板低竞价样本中，第三日竞价和第二天成交额是否存在稳定的分组差异
- 涨停日的开板行为与后续承接之间是什么关系，是否存在非线性

代码回测部分只统计数据和因子验证，不混入人工实盘结果，也不把主观题材判断当成可量化因子。题材、情绪和相对强度只用于解释交易逻辑，不进入现有统计口径。

## 研究设计

整个研究按同一套流程推进：

1. 先定义事件样本，例如连板断板、单板反包或二连板低竞价
2. 固定一个基准方案，避免每改一个条件就同时改变样本和结论
3. 每次只改变一个因子，比较分组后的胜率、平均收益、盈亏比和样本量
4. 所有交易加入佣金、印花税、过户费和滑点，买入和卖出时点保持一致
5. 结果分为正向、中性、负向和样本不足，不把高胜率的小样本直接当成结论
6. 从市场行为解释结果，例如竞价强弱代表开盘承接，成交额代表流动性和关注度，开板次数反映封板稳定性

详细方法见 [研究设计](./文档/研究设计.md)。

## 交易逻辑说明

### 连板接力说明

基于连板层级、竞价表现、题材共振和盘口承接进行候选股筛选。代码完成基础条件过滤，最终候选股结合题材强度和同题材个股相对强弱人工确认。

详见 [连板接力策略.md](./策略/连板接力策略.md)。

### 反包说明

基于前序涨停、断板调整、成交额和趋势位置构建候选池，再由人工结合题材、情绪和板块强度决定是否参与。

以上内容是交易逻辑说明。当前仓库的统计结果只验证代码因子，不验证人工题材筛选的实际收益。

### 统计边界

- 当前结果全部来自代码回测

- 卖出价使用卖出日 VWAP 作为统一执行基准，并扣除滑点

## 因子研究

研究区间为 2026-01-01 至 2026-09-30。
日线用于信号和交易规则，5 分钟数据用于判断涨停日是否开板。

当前结论：

- 第三日竞价：`0% 到 2%` 最好，胜率 51.63%，平均 +0.47%；
  `低于 -2%` 平均 +0.19%；`-2% 到 0%` 最差，平均 -0.79%
- 第二天成交额：`5 亿到 10 亿` 最好，平均 +0.69%；
  `20 亿到 40 亿` 最差，平均 -0.76%；`大于 40 亿` 平均 +0.67%，样本偏少
- 涨停日开板次数：`开板 2 次` 最好，平均 +1.74%；
  `开板 0 次` 最差，平均 -0.23%；`开板 1 次` 接近打平
- 开板状态来自 5 分钟近似判断，不是 Tick/L1/L2 精确统计
